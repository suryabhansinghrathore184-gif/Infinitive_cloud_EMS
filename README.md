# Infinitive_cloud_EMS

Enterprise Employee Management System & HR Operations Platform (EMS / HRMS).

## Tech Stack
- **Frontend**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **Charts & UI**: Recharts, Lucide Icons
- **Date Engine**: `date-fns` dynamic calendar math
- **Architecture**: Modular REST ready for NestJS + PostgreSQL + Prisma backend integration

## Features Implemented
- Admin / HR Dashboard (KPI Cards, Real Date Calendar, Turnout Donut Chart, Growth Line Chart)
- Employee Directory & Multi-Tab Profile Inspector (Personal, Employment, Emergency, Bank & Govt IDs)
- Organization Management (Departments, Designations, Locations, Reporting Hierarchy)
- Attendance Monitoring & Punch Logs
- Leave Request Approval Workflow & Policy Config
- Payroll Processing & Statutory Deductions (PF, PT, TDS)
- Performance Cycles, Goals & 360 Reviews
- Encrypted Document Vault
- Recruitment Requisitions & Candidate Pipeline
- Communication & Broadcast Announcements
- Multi-Channel Notification Center
- HR Helpdesk & Ticketing Workflow
- Executive Reports & PDF/Excel/CSV Exports
- System Settings & Module Configurations
- Immutable Audit Logs
- Integrations Gateway (WhatsApp API, Biometric, S3 Vault)

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` in your browser.
